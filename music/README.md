# Suas músicas

Coloque aqui arquivos de música (`.mp3`, `.ogg`, `.m4a`, `.wav`, `.flac`, `.opus`) — por exemplo,
a trilha clássica do jogo que você tiver. Elas entram no jogo automaticamente (`npm run dev`
ou `npm run build`) e tocam em ordem aleatória durante as corridas.

Os arquivos desta pasta **não** vão para o git (só este README), porque as músicas são suas.

No celular, use o botão **"Minhas músicas"** na tela de Som do jogo para escolher arquivos do
próprio aparelho — eles ficam guardados no navegador.

Sem nenhuma música, o jogo toca uma trilha de rock sintetizada, com um tema por planeta.
